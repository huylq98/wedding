# Danh Sách Nhạc Cưới (Wedding Playlist)

Thư mục lưu trữ danh sách bài hát, kịch bản âm nhạc và các file nhạc cho đám cưới của **Quốc Huy & Thu Phương**.

> **Lưu ý:** Thư mục này hoàn toàn độc lập và **không ảnh hưởng** đến mã nguồn website đang deploy trên GitHub Pages / Cloudflare.
